## 📖 Deskripsi Proyek

Proyek ini mensimulasikan sistem Smart Room Monitoring menggunakan protokol MQTT dengan pola komunikasi publish-subscribe.

Publisher berperan sebagai sensor virtual yang mengirimkan data:

- Temperature
- Humidity
- Light

Mosquitto berperan sebagai broker MQTT.

Subscriber berperan sebagai aplikasi monitoring yang menerima data dari broker.
